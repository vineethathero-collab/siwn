1. Project Overview & Architectural Scope

The Siwmaga Dharmayathanaya Web Portal is an international Buddhist educational platform designed to connect students, teachers, parents, and devotees across Sri Lanka and overseas communities (Japan, UK, Italy, Australia, Qatar, Canada, USA).

  • Dual-Language Multi-Page Architecture: Full localization across Sinhala (index.html, gallery.html) and English (index-en.html, gallery-en.html) with verified hreflang alternate tags for global search engine indexing.
  • Microsoft Teams Remote Class Integration: Interactive timetable supporting live time-zone conversions (BST, AEST, CEST, JST, AST, EDT) with automated "Live Now" status calculations based on Sri Lanka Standard Time (UTC + 5:30).
  • Zero-Framework Vanilla JS Engine: Clean, modular, memory-leak-free JavaScript executing client-side data binding without bloated runtime dependencies.

3. Performance & Speed Optimizations Executed

3.1 Compiled Static CSS (Elimination of Tailwind Play CDN)

Migrated from runtime client-side Play CDN compilation (cdn.tailwindcss.com) to pre-compiled static stylesheets (style.css & gallery.css). This eliminates ~350KB of JIT compiler JavaScript, saves main-thread execution time, and prevents Flash of Unstyled Content (FOUC).

3.2 Font Delivery Optimization (preconnect & display=swap)

Implemented DNS pre-connection via rel="preconnect" for Google Fonts and Google Static CDN. Applied display=swap to eliminate invisible text during font loading (FOIT), ensuring rapid First Contentful Paint (FCP).

3.3 Cumulative Layout Shift (CLS) Prevention & Native Lazy Loading

Every image container is structured with explicit aspect-ratio constraints and animated CSS shimmer skeletons (.shimmer-skeleton). Below-the-fold assets use browser-level loading="lazy" and decoding="async".

3.4 Background Resource Management via Page Visibility API

Utilized document.addEventListener('visibilitychange', ...) to automatically freeze hero sliders, news carousels, and gallery background polling when the browser tab is hidden, minimizing CPU and battery consumption on mobile devices.

3.5 60fps Mobile Scroll Optimization ({ passive: true })

All scroll and resize event listeners use { passive: true } to avoid blocking the browser compositor thread, guaranteeing smooth 60fps mobile scrolling.

3.6 Dynamic Resolution Caching for Gallery Images

Media thumbnails are requested from Google Drive using targeted size parameters:

  • Grid View: sz=w600 (lightweight ~45KB WebP/JPEG thumbnails)
  • Full Lightbox View: sz=w1600 (high-resolution full quality loaded on demand)
  • Local Storage Cache: Cached with a 60-second TTL to eliminate redundant network round trips.

4. Code Standards, Accessibility & Security

  • Semantic HTML5: Clean document outline with dedicated <header>, <main id="main-content">, <section>, and <footer> tags.
  • Accessibility (WCAG 2.1 AA): Added explicit aria-label tags on all icon controls, ARIA modal attributes (role="dialog", aria-modal="true"), keyboard navigation for sliders (← / →), and Escape key modal dismissal.
  • Web Security & Reverse Tabnabbing Protection: All external links (Microsoft Teams, Zoom, YouTube, Facebook, WhatsApp, Google Forms) strictly enforce: 
    <a href="..." target="_blank" rel="noopener noreferrer">
    This protects users from malicious window-opener redirection and cross-tab performance degradation.
